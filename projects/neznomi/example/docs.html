Getting Started · 5 min read

はじめに

neznomi は、セマンティックな HTML を素直に組むだけでモダンなアプリ UI になる、 クラスレス & 構造駆動の CSS フレームワークです。

インストール

単一の CSS ファイルをリンクするだけで導入できます。ビルドステップはありません。

<link rel="stylesheet" href="https://example.com/neznomi/app-classless.css">

ローカルに置く場合は app-classless.css をプロジェクト配下にコピーしてください。

Tip color-scheme: light dark をルートで宣言済みなので、フォームコントロールなどもシステム設定に追従します。

基本のセットアップ

典型的なページ構造は次のとおりです。コンテンツに class をほとんど付けません。

<!doctype html>
<html lang="ja">
  <head>
    <meta charset="utf-8" />
    <link rel="stylesheet" href="./app-classless.css" />
  </head>
  <body>
    <main class="container">
      <header>
        <h1>My App</h1>
      </header>
      <section>
        <h2>Hello</h2>
        <p>最小構成のページです。</p>
      </section>
    </main>
  </body>
</html>

アプリシェル（左ナビ + メイン）が欲しいときは <div class="container app"> をルートに置きます。

クラスレス指向

要素そのものの意味（タグ）と、状態を示す ARIA 属性をスタイルの主たるフックにしています。 これにより、コンポーネントごとの命名規則を覚えずに済み、HTML を読むだけで構造が把握できます。

「クラス名を考える時間」を「意味のあるマークアップを書く時間」に置き換える、という方針です。

強調や色付けが必要なときだけ .primary / .danger などの文脈クラスを使います。

デザイントークン

カラーや角丸、シャドウなどはすべて CSS 変数で公開されています。テーマ拡張は :root に変数を上書きするだけです。

--text本文テキスト#1a1a1a
--surface区切り面（サイドバー / タブバー）#f7f8fa
--primary主要アクション#3b82f6
--radius角丸の基準8px

FAQ

カスタムクラスは作るべき？

原則不要です。要素 + 文脈クラス（.primary など）の組み合わせで表現してください。

SSR / 静的サイトに使える？

使えます。ビルドは不要で、CSS をリンクするだけです。

JavaScript は必要？

大半は CSS だけで動作します。タブ切替やテーマ切替などインタラクションのみ JS を書いてください。
